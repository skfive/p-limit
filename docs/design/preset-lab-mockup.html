4. 반응형 (frozen §5.6)

· ≥ 480px: 프리셋 controls·메트릭 가로 배치 (flex row 균등)
· < 480px: .preset-lab__controls·메트릭 세로 stack (창 너비를 480px 미만으로 줄여 확인)
· ≥ 320px 전 범위: box-sizing:border-box + max-width:100%로 가로 overflow 없음
· 카운터 수치 tabular-nums로 자릿수 폭 안정화
